Assets públicos del sitio
=========================

Contenido principal:
- /icons/*      → iconos PWA, apple-touch y favicons PNG.
- /og/*         → imagen Open Graph 1200×630.
- favicon.ico   → favicon principal.
- site.webmanifest

Notas de mantenimiento:
- Este proyecto usa Next.js Pages Router.
- Los enlaces de iconos, manifiesto y metadatos globales se mantienen desde la estructura real del proyecto.
- No agregar, mover ni reemplazar assets reales sin verificar primero sus referencias en el código.
